# Instructions for Claude

- Never add `Claude-Session:` trailers or claude.ai links to commit messages or pull requests.
  This covers PR titles and bodies too: remove any "Generated by Claude Code" footer that links to a
  claude.ai session, including one a tool appends automatically.
- Never mention Notion, internal cards, employers, schedules or personal details in commits, docs or PR text.
- Before pushing or opening/editing a PR, run the privacy check on commits *and* the PR text:
  `git log main..HEAD --format=%B | grep -iE "claude-session|claude.ai|notion"` and the same grep over
  the PR title and body (re-read the PR after creating or editing it). Both must print nothing.
